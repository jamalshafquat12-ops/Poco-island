# Poco Island Functional V1.1

Target: POCO X5 / Android 12+.

Features:
- Dynamic Island-style overlay
- Music controls: previous / play-pause / next via active MediaSession
- Notification popups via NotificationListenerService
- Incoming/connected/ended call indicators
- Charging percentage popup
- Music-volume popup
- No internet, account, ads or analytics

Install:
1. Open in Android Studio.
2. Connect POCO X5 with USB debugging.
3. Run the app.
4. Enable overlay permission.
5. Enable Notification Access.
6. Grant phone permissions.
7. Tap Start Poco Island.

Important:
- Android/Xiaomi permission and background-management behavior varies by device/software version.
- This source is intended to be built and tested on the target POCO X5; it is not presented as a pre-signed production APK.
